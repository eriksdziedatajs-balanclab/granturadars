# Grantu Radars – granturadars.lv

Statiska mājaslapa (HTML/CSS/JS), publicēta caur Netlify.

- `index.html` – uzņēmumiem, `privatpersonam.html` – privātpersonām
- `programmas.js`, `privatpersonam.js` – programmu dati (atjaunojami automātiski)
- `programmas/` – programmu ceļveži, `cenas.html`, `finansesana.html`, `noteikumi.html`, `privatuma-politika.html`

Publicē automātiski no `main` zara (Netlify).
